# Agent skills

Configuration read by the mattpocock-skills plugin's engineering skills (`to-tickets`,
`triage`, `to-spec`, `domain-modeling`, `code-review`, etc.) when working in this repo. This is
plugin/skill config, not project documentation — see `CLAUDE.md` for that.

## Issue tracker

Issues live as GitHub Issues on `github.com/jovstern/ai-presenter-agent`, via the `gh` CLI. See
`issue-tracker.md`.

## Domain docs

Single-context layout (one `CONTEXT.md` + `docs/adr/` at the repo root, created lazily by
`/domain-modeling`). See `domain.md`.
